# NeuroForge Enterprise Frontend

This is a simple responsive frontend for the NeuroForge Spring Boot backend.

## Run
1. Start the backend first on `http://localhost:8080`.
2. Open `index.html` in a browser. If your browser blocks local API requests from file://, run a small static server from this folder, for example `python -m http.server 5500`, then open `http://localhost:5500`.
3. The frontend calls REST APIs under `http://localhost:8080/api`.

## Modules
Dashboard, Users, Projects, Sprints, Tasks and Bug Reports.
